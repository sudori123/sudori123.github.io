# 見抜き算（MINUKIZAN）

敵が隠した3桁の数字を推理して戦う、デッキ構築ダンジョンRPG。
インストール不要、ブラウザですぐ遊べます。

- サイト: https://sudori123.github.io/
- ゲーム: https://sudori123.github.io/minukizan/

## あそび方

「ヒット」（数字も位置も一致）と「ブロー」（数字は合うが位置違い）を手がかりに、
敵の3桁の数字を絞り込んでいきます。当てた分だけ相手にダメージが入ります。

- 1人プレイ（冒険モード）／2人プレイ（同じ端末で交代して対戦）
- カードを集めてデッキを組み、パッシブや装備で強化していきます
